Ramble Scribe 🎙️✨

Crystallize your raw thoughts.

Ramble Scribe is a privacy-first, completely ad-free web application designed for writers, thinkers, and anyone who needs to dump their thoughts out loud. It leverages your browser's native Web Speech API to transcribe your microphone input locally—meaning no server costs, no API keys, and no digital spam.

Built with usefulness in mind, it is designed to be the perfect companion for formatting and outlining books, essays, or daily notes.

🚀 Features

Continuous Native Dictation: Auto-resumes listening even if you pause to gather your thoughts.

Custom Punctuation Engine: Use intuitive voice commands to insert exact punctuation (e.g., say "full stop" for a ., or "comma" for a ,).

Number Parsing: Automatically catches and formats spoken numbers (saying "num 5" outputs 5).

Formatting Tools: One-click "Fix Spacing" button to instantly clean up trailing or double spaces caused by speech delays.

Export & Copy: Instantly copy your transcript to the clipboard or download it as a beautifully formatted .txt file for use in AI editors (like Gemini) or word processors.

Dark Mode Default: Sleek, low-glare UI optimized for long, late-night writing sessions.

Mobile-Ready: Fully responsive design that works brilliantly on desktop and mobile browsers.

🛠️ Installation & Setup

This is a standard React application. To run it locally:

Clone the repository:

git clone https://github.com/yourusername/ramble-scribe.git


Navigate to the directory:

cd ramble-scribe


Install dependencies:

npm install


Start the development server:

npm run dev


Note: For the best speech recognition experience, we highly recommend using Google Chrome or Microsoft Edge, as they have the most robust implementations of the Web Speech API.
